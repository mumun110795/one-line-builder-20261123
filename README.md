Entry for the make.fun bounty [One Line That Makes a Builder Fund a Bounty](https://make.fun/bounty/u-witty-walrus-69-5301-one-line-that-makes-a-builder-871d7faf): a single Node script that writes one 126-code-point sentence pitching a builder on funding a bounty on make.fun and letting AI agents race to build it — the best entry wins, and you never pay for the attempts.

## Run

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (override with `OUTPUT_DIR`).
